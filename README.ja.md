# ctxtray

Claude Code のコンテキスト使用量とレート枠を、Windows の画面に常に表示しておく常駐ツールです。

[English README](README.md)

Claude Desktop でもこれらの値は確認できますが、インジケーターをクリックしないと表示されず、
そのたびに作業の手が止まります。ctxtray は同じ値を、常に最前面にある小さなパネルと、
トレイアイコンに表示し続けます。

トレイアイコンは、値ごとに分ける表示（左）と、1 個にまとめる表示（右）から選べます。

> **非公式のツールです。** Anthropic とは関係がなく、同社の承認や支援も受けていません。
> Claude は Anthropic, PBC の商標です。

## できること

- **セッションごとのコンテキスト使用量**：Claude Desktop の Code タブと、
  ターミナルや VS Code で実行中の Claude Code が対象です。
- **5時間枠と週間枠**の使用率と、5時間枠のリセット時刻（記録の履歴からの推定。既定では注意の値を超えたときだけ表示）
- しきい値を超えたときの**通知**（値ごとに、注意と危険のどちらで（または両方で）通知するかを選べます）

## しないこと

ctxtray が読むのは、Claude Desktop と Claude Code が書き出したファイルだけです。読み取り専用で開きます
（[一覧は後述](#読むファイルと通信)）。

- Claude Desktop を改変しません（`app.asar` の書き換え、スクリプトの注入、Electron fuse の変更など）。
  コードの逆コンパイルや解析もしません。
- 公開・非公開を問わず、Anthropic の API にはアクセスしません。
  保存されたログイン情報（OAuth トークンやセッション Cookie）も読みません。
- 会話の記録から使うのは、トークン数、時刻、モデル名、エフォートだけです。
  会話の本文を表示したり、保存したり、送信したりはしません。
- **既定では、ネットワーク通信を一切行いません。** 設定でオンにできる通信は 2 つだけで、
  どちらもログイン情報や会話の情報は送りません（[後述](#読むファイルと通信)）。
- 更新を自動でインストールしません。
- `~/.claude/settings.json` を書き換えません（hooks も statusLine も使いません）。

## インストール

1. [Releases](../../releases) から `ctxtray-<バージョン>-win-x64.zip` をダウンロードし、展開します。
2. `ctxtray.exe` を、今後も置いておくフォルダーに移動します（例: `%LOCALAPPDATA%\Programs\ctxtray\`）。
   OneDrive で同期しているフォルダー（デスクトップやドキュメントのことがあります）と、
   `C:\` の直下に自分で作ったフォルダーは避けてください。他の端末や他のユーザーが中のファイルを書き換えられるため、
   書き換えられた exe がサインインのたびに実行されるおそれがあります。
3. `ctxtray.exe` を実行します。インストーラーや追加のランタイムは必要ありません。
   コード署名をしていないため、初回は SmartScreen の警告が表示されます。「詳細情報」>「実行」の順にクリックしてください。
4. サインインのたびに自動で起動するには、トレイアイコンを右クリックして「サインイン時に起動」を選択します
   （「設定 > 全般」でも同じ操作ができます）。
   あとで `ctxtray.exe` を別の場所に移動した場合は、新しい場所から一度起動し、「サインイン時に起動」をもう一度オンにしてください。

動作環境: Windows 10 バージョン 1903 以降、または Windows 11（必要な .NET Framework 4.8 は OS に標準で含まれています）。
動作を確認しているのは、Windows 11（25H2、表示倍率 150%）と、Claude Desktop に同梱の Claude Code 2.1.284 です。
Windows 10 では確認していません。

ダウンロードしたファイルが本物かどうかは、[ダウンロードしたファイルの確認](docs/verify.ja.md)の手順で確かめられます。
ビルド済みのファイルを使いたくない場合は、[自分でビルド](#ビルド)することもできます。

### 新しいバージョンを知るには

「設定 > 全般」の「新しいバージョンを確認する」をオンにすると、1 日 1 回 GitHub で最新のバージョン番号を確認し、
新しいバージョンがあれば通知します（既定はオフ。入れ替えはご自身で行ってください）。
オフのままにしたい場合は、このリポジトリ上部の「Watch」>「Custom」>「Releases」をオンにすると、GitHub から通知が届きます。

## 使い方

| 操作 | 動作 |
|---|---|
| `Ctrl+Alt+C` | パネルの表示／非表示（キーは設定で変更できます） |
| ドラッグ | パネルを移動 |
| 行にマウスを合わせる | 詳細を表示（名前の全文、モデルとエフォート、トークン数、自動圧縮までの残り、値が記録された時刻） |
| トレイアイコンをクリック | パネルの表示／非表示 |
| トレイアイコンまたはパネルを右クリック | メニューを表示（設定、クリックを透過、サインイン時に起動、終了など） |

- セッション名の左の**丸**は、Claude Desktop のサイドバーの丸と同じ意味です。
  黄は承認待ち、回答待ち、対応が必要な未読の応答、青は未読の応答、灰は応答中、輪は応答が終わったか、プロセスが実行されていないことを示します。
  黄の丸が何を待っているかは、行にマウスを合わせると表示されます。設定で、対応が必要な行を強調することもできます。
- セッション名が**灰色**の行は、その Claude Code のプロセスが実行されていないことを示します。
  トレイアイコンと通知の対象からは外しています。
- レート枠の見出しに「**参考値**」と表示されているときは、Claude Desktop が起動していないか、
  24 時間以上記録が更新されていないため、最後に記録された値を表示しています。
- 「**○分前に記録**」と表示され値が灰色のときは、使用中なのに Claude Desktop が新しい値を記録していません。
  Claude Desktop を再起動すると直ることがあります。
- パネルは、**画面共有とスクリーンショットには写らないように**しています（自分の画面には表示されます）。
  会議で画面を共有したときに、セッション名が見えないようにするためです。
  Windows の機能を使っているため、撮影の方法によっては写ることがあります。
  Windows 10 バージョン 2004 より前では、中身の無い四角として写ります。設定でオフにできます。

表示する値、色が変わるしきい値、通知、トレイアイコンの形などは、トレイメニューの「設定…」で変更できます。

- 詳しい使い方（トレイアイコンの 2 つの表示方法、レート枠の読み方、通知、自動圧縮、モデルとエフォートなど）:
  [docs/usage.ja.md](docs/usage.ja.md)
- 設定ファイルの全項目とコマンドライン: [docs/configuration.ja.md](docs/configuration.ja.md)
- 仕組みの詳細（英語）: [docs/how-it-works.md](docs/how-it-works.md)

## 読むファイルと通信

| 読み込むファイル | 用途 |
|---|---|
| `plan-usage-history.json` | 5時間枠と週間枠の % |
| `claude-code-sessions/**/local_*.json` | 開いているタブと、そのモデルと作業フォルダー、タブを最後に開いた時刻、最後の応答の分類（完了／対応が必要） |
| `~/.claude/projects/**/*.jsonl` | `usage` フィールドのトークン数と、その応答のモデルとエフォート、時刻 |
| `~/.claude/sessions/<pid>.json` | 実行中の Claude Code のプロセスと、その状態（応答中・承認待ちなど） |

この他に、次の情報を Windows から取得します。

- Claude Desktop と Claude Code のプロセスが実行中かどうか（プロセスの名前、実行ファイルの製品名、開始時刻）
- 全画面表示のアプリを使っているかどうかと、前面のウィンドウがどのプログラムのものか
  （全画面表示のアプリの上ではパネルを非表示にし、Claude Desktop の上では非表示にしないため）
- Windows のライト／ダークの設定

書き込むのは、`%LOCALAPPDATA%\ctxtray\` の中にある ctxtray 自身のファイル（設定など）と、
「サインイン時に起動」をオンにしている間のスタートアップのショートカットだけです
（一覧は [docs/configuration.ja.md](docs/configuration.ja.md#書き込むファイル)）。

通信するのは、設定で次のどちらかをオンにした場合だけです。

- 「上限が不明なモデルを公式ドキュメントで調べる」（設定 > モデル）:
  ctxtray に登録されていないモデルを見つけたときに、`platform.claude.com` の公開ドキュメントからそのモデルのページを読み込みます。
  見つからなかったモデルは 24 時間後にもう一度確認します。
- 「新しいバージョンを確認する」（設定 > 全般）:
  GitHub の公開 API から、最新リリースのバージョン番号を 1 日 1 回読み込みます。失敗した場合は 1 時間後にもう一度確認します。

## 制限事項

- **読み込んでいるファイルの形式は、Claude の内部仕様です。** アップデートで変わる可能性があります。
  読み取れなくなった場合は、推測で値を埋めずに「不明」と表示しますが、ctxtray の修正が必要になります。
- **コンテキストの値は 1 ターン遅れます。** トークン数は応答が終わった時点で書き込まれるためです。
- **レート枠の値は、実際の使用量より遅れることがあります。** Claude Desktop が使用量を記録するのは
  5〜15 分ごとで、アプリを使っている間だけです。Claude Desktop を閉じている間は更新されません。
- **ctxtray に登録されていないモデルは、% の代わりに `?%` と表示します。** 「設定 > モデル」で上限を選択すると % が表示されます。
- **ctxtray は Claude Code の設定を読みません。** `/autocompact` で自動圧縮の位置を変えた場合は、
  「設定 > 全般」の「自動圧縮」にも同じ値を入力してください（[詳しく](docs/usage.ja.md#自動圧縮が起きる位置)）。
- 通知は、Windows の通知センターに残りません（従来のバルーン通知を使っているため）。
- パネルはスクリーンリーダーで読み上げられません。同じ値は、トレイアイコンのツールチップと
  `ctxtray --status` で確認できます。

## サポートとバージョン

- 個人が作っているツールです。不具合の報告や要望は [Issues](../../issues) へどうぞ（日本語、英語どちらでも）。
  対応は不定期です。
- 報告に `ctxtray --json` の出力を貼るときは、セッション名（`title`）、フォルダーのパス（`cwd`）、
  ユーザー名を含むパス（`paths`、`transcript`）を消してから貼ってください。
- 0.x の間は、設定ファイルの項目の意味や既定の表示が変わることがあります。
  その場合は 2 番目の数字を上げ（例: 0.11 → 0.12）、変わる点をリリースノートの先頭に書きます。
  `--json` の出力は状態を調べるためのもので、項目が変わることがあります。
- 変更の履歴は [Releases](../../releases) にあります。

## アンインストール

1. トレイアイコンを右クリックし、「サインイン時に起動」をオフにします。
2. トレイアイコンを右クリックし、「終了」を選択します。
3. `ctxtray.exe` と、`%LOCALAPPDATA%\ctxtray` フォルダーを削除します。

## ビルド

`net48` をターゲットにできる .NET SDK が必要です（参照アセンブリは、最初のビルド時に NuGet から自動的に取得されます）。

```
dotnet build src/CtxTray/CtxTray.csproj -c Release
```

出力先は `src/CtxTray/bin/Release/ctxtray.exe` で、この exe だけで動作します。
テストは次のように実行します（失敗があれば終了コード 1 を返します）。

```
dotnet build tests/CtxTray.Tests/CtxTray.Tests.csproj -c Release
tests/CtxTray.Tests/bin/Release/ctxtray-tests.exe
```
